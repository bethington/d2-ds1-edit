INTRODUCTION

Cette page est dédiée à la description de la structure du fichier D2S, pour ce que j'arrive à en comprendre. Au départ je voulais faire un programme qui permettrait d'éditer n'importe quoi dans les sauvegardes de Diablo II (statuts, aptitudes, quêtes, portails, mercenaires, objets, ...)

Il existe un grand nombre de programmes sur Internet qui permettent déjà de faire cela. Si j'ai voulu faire le mien, c'est parceque la plupart d'entre eux ne marchaient pas avec mes sauvegardes personnelles (problème de version). Et puis, je trouve simplement intéressant de savoir comment fonctionne mon jeu favori :)

A l'époque où je cherchais à rassembler de la documentation à ce sujet sur Internet, je me suis rendu compte que ces docs étaient la plupart du temps : rares, incomplètes, quelquefois imprécises, et difficiles à comprendre pour certains passages. La première chose à faire était de construire une base de connaissances sur les fichiers D2S aussi complète que possible. J'ai donc commençé de faire ma propre documentation. C'est la quête la plus difficile que j'ai jamais eu dans ce jeu ;) . Cette doc est le résultat de plusieurs heures (semaines ?) passées à vérifier les docs que j'avaient, et à deviner le reste.

Aujourd'hui, je pense que je ne peux que maintenir une référence html, parce que cela représente déjà tant de travail...
