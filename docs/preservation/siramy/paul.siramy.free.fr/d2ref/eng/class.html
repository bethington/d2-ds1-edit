PLAYER CLASS

 This page is correct if you have the patch 1.08. It has inserted the 2 new class from the expansion (druid and assassin) after the usual characters, so the ancient class 05, 06 and 07 are now the class 07, 08, 09 and so on.

This value determine your skills and apparence. You can change your class at any time (but your skills will change too, according to your new character).

Only the 5 first values are valid. The two next are reserved for the expansion, and all others have the name "An Evil Force". If you try an invalid value, the game will freeze.
