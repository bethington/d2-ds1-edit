PLAYER LEVEL COPY

 This value seems to be the level of the player. Well, sort of. But it's not the true value. It's just a copy of a data which is far away in the file (in the statut datas, more precisely).

When you open a game, in the menu, you choose the character that you want to play. At this moment the player's level is indicate. The player level copy value is used there : THIS is the value that is read while in the menu.

If you try to change this value, it seems OK while still in the file menu, but if you begin to play, and then check your statut, you'll see that your level is the same as before your patch. That's because you have not change the RIGHT value.

The TRUE player level is a bit complicated to find. It is a part of the STATUT DATAS, and so, it have no fixed offset, due to the fact that some of the statut datas may not be present.

Check the part 2 for a description of the statut datas.
