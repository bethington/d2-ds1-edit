MODE HARDCORE

Cette donnée indique si le joueur est en mode hardcore et / ou s'il est en vie. Depuis l'Extension "Lord of Destruction", elle indique aussi si la sauvegarde est en mode extension.

Bit 2 : est posé quand le joueur est en mode hardcore, sinon est absent (mode normal)
Bit 3 : est posé si le joueur est déjà mort, est absent s'il est en vie
Bit 5 : est posé si en mode extension (sauvegarde aussi bien convertie que nouvellement crée), est absent sinon

Valeurs possibles pour l'ensemble de la donnée, et leurs significations :

  • 00h : mode normal, jamais mort
  • 04h : mode hardcore, en vie
  • 08h : mode normal, est déjà mort
  • 0Ch : mode hardcore, mort

  • 20h : extension, mode normal, jamais mort
  • 24h : extension, mode hardcore, en vie
  • 28h : extension, mode normal, est déjà mort
  • 2Ch : extension, mode hardcore, mort
Note : quand le joueur est en mode hardcore ET est mort, la donnée de statut vie actuelle est absente.

Pour rescuciter un joueur mort en hardcore, vous n'avez seulement besoin que de changer la valeur de 0Ch en 04h (ou de 2Ch en 24h si c'est une sauvegarde en mode extension). Quand vous commencerez de jouer, votre vie sera égale à 1 à cause du problème de la vie actuelle, mais vous pouvez facilement la remplir. N'oubliez pas de récupérer votre cadavre, pour retrouver votre équipement. Maintenant, vous êtes un joueur hardcore vivant, tout ce qu'il y a de plus normal.

Astuce : à tout moment vous pouvez passer d'un mode à l'autre. Vous pouvez donc développer un personnage puissant en mode normal, puis passer au mode hardcore. L'inverse est aussi vrai : si vous avez des problèmes pour tuer un boss en hardcore, vous pouvez passer au mode normal. Après l'avoir tué, vous pouvez repasser au mode hardcore.

Malgrès ce que je viens d'écrire juste au dessus, je considère que changer de mode est une faute impardonnable !
