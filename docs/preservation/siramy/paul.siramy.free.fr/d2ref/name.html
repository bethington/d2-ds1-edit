NOM DU JOUEUR

 Les caractères autorisés que vous pouvez utiliser sont :
  • les lettre minuscules (de a à z)
  • les lettre majuscules (de A à Z)
  • le signe moins (-), mais seulement s'il est entouré de 2 autres lettres. Notez qu'il ne peut y avoir qu' 1 seul signe moins dans le nom.
  • depuis le patch 1.08 vous pouvez aussi utiliser le caractère souligné (_), qui se comporte exactement comme le signe moins.
Note : vous ne pouvez pas utiliser le signe moins et le caractère souligné en même temps. C'est l'un ou l'autre, ou aucun des deux, mais pas les deux.

La longueur du nom doit être comprise entre 2 et 15 caractères, et doit être suivie par un caractère zéro (pas le caractère "0", mais par le caractère avec la valeur ASCII 0).

Tous les noms de fichier (D2S, KEY, MA*) doivent correspondrent avec la donnée nom (et tout spécialement le fichier D2S), sinon le jeu pensera que vous trichez : vous serez "récompensé" en redémarant une partie du départ. Quand le jeu fait cette analyse, la casse des lettres n'est pas significative : le nom du fichier deviendra le nom dans la donnée. Mettre des caractères illégaux dans le nom (comme des chiffres, des espaces, des caractères spéciaux, ...) est laissé comme un exercice pour le lecteur. Cependant, j'ai déjà renommé des personnages avec un nombre dans leur nom, SANS problèmes.

Noms valides :

  • Paul
  • PaulTheBrave
  • Jean-Michel
  • Paul-jr
Noms invalides (même si certains d'entre eux peuvent être acceptés)
  • Paul The Fool
  • Paul2
  • Paul_test   (cependant, valide depuis la version 1.08)
  • Paul&co
