ETAT DES DIALOGUES AVEC LES PNJ


Il semblerait que ces données soit utilisées pour conserver l'état des dialogues avec les PNJ (Personnages Non Joueurs). Je n'ai pas eu le temps de tout analyser encore.

Il y a 2 données pour chaque niveau de difficultés. Chacune de ces données fait 8 octets. Seul les 4 premiers octets sont utilisés (1 octet par acte, j'en suis pratiquement sûr), les 4 autres sont toujours égal à zéro (réservés pour un usage future ?) .

Description non-exhaustive de l'octet de poid faible de la Donnée 1 (octet à l'offset 200h) :

Bit 0 : ?
Bit 1 : Introduction de Gheed
Bit 2 : Introduction d'Akara
Bit 3 : Introduction de Kashia
Bit 4 : ?
Bit 5 : Introduction de Charsi
Bit 6 : ?
Bit 7 : Quelque chose (mais pas pour Cain je pense)

Pour les bits d'introduction : s'il est absent, le PNJ vous donnera son discours d'introduction la première fois que vous lui parlerez. S'il est posé, il vous l'a déjà donné. La preuve : après que le bit soit posé, enlevez-le, et le PNJ recommencera son discours.
