CONFIGURATION JOUEUR I OU II
Cette valeur n'est présente que dans une sauvegarde avec l'Extension.
C'est la configuration atuelle arme / bouclier que le joueur a sélectionné.

Si on trouve 00 00 c'est la configuration I
Si on trouve 01 00 c'est la configuration II

Dans une sauvegarde sans l'Extension, on trouve toujours 00 00
