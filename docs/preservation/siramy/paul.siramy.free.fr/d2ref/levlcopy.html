NIVEAU DU JOUEUR (COPIE)

 Cette valeur semble être le niveau du joueur. C'est un peu ça, mais ce n'est pas la véritable valeur. Ce n'est qu'une copie d'une donnée qui est bien plus loin dans le fichier (dans les données de statut, plus précisément).

Quand vous lancez le jeu, dans le menu, vous choisissez le personnage que vous vous voulez jouer. A ce moment le niveau du joueur est indiqué. La donnée niveau du joueur (copie) est utilisée ici : c'est ELLE qui est lue pendant que vous êtes dans le menu.

Si vous essayez de changer cette valeur, tout semblera aller bien tant que vous resterez dans le menu du choix du personnage, mais si vous commencez de jouer, et que vous regardez vos statut, vous verrez que votre niveau est le même qu'avant votre modification. C'est parceque vous n'avez pas changé la BONNE valeur.

Le VERITABLE niveau du joueur est un peu compliqué à trouver. Il fait partie des DONNEES DE STATUT, et par conséquent, il n'a pas d'offset fixe, pour la bonne raison que certaines des données de statut peuvent ne pas être présente.
