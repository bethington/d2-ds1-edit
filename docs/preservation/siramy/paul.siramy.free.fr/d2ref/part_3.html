DESCRIPTION DU FICHIER   (Partie 3, données intéressantes à modifier : niveaux d'aptitude)


Juste après les données de statut, nous trouvons l' entête des aptitudes. Elle est égale à 6669h. Si nous ne trouvons pas cette valeur, c'est peut être la cause du champ de bits réservé dans les données de statut : s'il n'est PAS égal à zéro, alors c'est peut être un problème de version.

Nous trouvons ensuite les données d'aptitude. C'est un tableau de 30 octets. Chaque aptitude utilise 1 octet, allant de 0 à 20 (14h). Leur ordre n'est pas ce que vous pourriez penser : les 10 premieres aptitudes ne sont PAS les 10 aptitudes que vous trouvez dans l'onglet d'aptitude #1. La clef primaire de l'ordre de tri est le niveau minimum requis, et la clef secondaire est l'onglet d'aptitude : l'onglet #3, puis le #2, et enfin le #1.

Pour chaque personnage dans les tableaux suivants, il y a 2 colonnes. La première est le nom de l'aptitude à un offset relatif donnée, et la seconde est un code : une lettre suivie d'un nombre. La lettre indique l'onglet d'aptitude où se trouve l'aptitude, et le nombre indique le niveau minimum requis. Voici la correspondance des lettres avec les onglets d'aptitudes :

Puisque nous ne savons pas à quel offset commencent les données, les offsets donnés ci-dessous sont RELATIFS. Par exemple, si l'offset de l'Entête d'aptitude est 26Dh, alors le début des données d'aptitudes est 26Fh. Ce sera la base. Si le joueur est une Amazone, nous savons que l'aptitude Coup Critique est à l'offset 272h (26Fh + 3), et que la dernière aptitude (Eclairs en Furie) est à l'offset 28Ch (26Fh + 29).
