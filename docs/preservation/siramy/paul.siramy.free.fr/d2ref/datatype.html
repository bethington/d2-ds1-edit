TYPES DE DONNEES

 Les différents type de données que j'utilise sont exposés ici. Pour vous, programmeurs, la plupart d'entre eux devraient être évident.

Tableau : Un tableau de X éléments de Y octets chacun. X * Y donne la taille totale du tableau
Chaîne : Tableau spécial. ("Taille totale" - 1) éléments maximum, suivi d'un 0 (zéro)
Champ de bits : Chacun des bits de la valeur a une signification spéciale
Valeur : Une valeur directe. Octet de poid faible d'abord, de poid fort ensuite (standard Intel)
Entête : Une série de valeurs connues
Réservé : Une série de 0 (zéro)
Structure : Une structure est un ensemble de données. Chaque cas sera expliqué
? : Encore inconnu
