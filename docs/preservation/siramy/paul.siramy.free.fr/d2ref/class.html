CLASSE DU JOUEUR

 Cette page est correcte si vous avez le patch 1.08. Il a inséré les 2 nouvelles classes de l'extension (druide et assassin) après les personnages habituels, donc les anciennes classes 05, 06 et 07 sont maintenant les classes 07, 08, 09 et ainsi de suite.

Cette valeur détermine vos aptitudes et votre apparence. Vous pouvez changer de classe à tout moment (mais vos aptitudes changeront aussi, en fonction de la classe que vous choisirez).

Seul les 5 premières valeurs sont valides. Les 2 suivantes sont réservées à l'extension, et toutes les autres ont le nom "Une Force Maléfique". Si vous essayez une valeur invalide, le jeu se bloquera.
