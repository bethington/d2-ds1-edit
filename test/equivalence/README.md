# Original-game equivalence evidence

This directory holds comparison contracts, authored inputs, and small recorded
original-game results for vanilla Diablo II 1.13c. Code lives in
`scripts/equivalence/` (Python standard library only, except the local corpus
lane, which needs `mpyq`; see `requirements-local.txt`).

There are three lanes:

| Lane | Needs | What it shows |
| --- | --- | --- |
| Portable replay (CTest `equivalence_palette_replay`, label `portable`) | Python 3, the built probe | The editor still agrees with the recorded original answers for the declared inputs |
| Local corpus (`baseline.py`) | A licensed 1.13c installation, `mpyq` | Which binaries, archives and effective asset bytes the reference is |
| Live reference (`capture_palette.py`) | A privileged, idle 1.13c d2-fleet member, the d2-fleet checkout, `D2FLEET_TOKEN` | Fresh original answers for the same contract |

A recorded replay is a regression check against one capture. Agreement covers
the contract's finite input set, not every possible input.

## Schemas

All digests are SHA-256 of canonical JSON (UTF-8, sorted keys, `,`/`:`
separators), omitting only the object's own top-level `digest` field
(`contracts.canonical_digest`). Payload hashes (`input_sha256`,
`output_sha256`, `abi_recipe_digest`, `adapter_digest`) hash the canonical JSON
of the named payload with nothing omitted.

- `ds1edit.contract/1`: `id`, `kind`, `baseline_digest`, `reference`
  (`module`, `rva` as lower-case `0x` hex, `function_bytes_sha256`,
  `abi_recipe_digest`, optional embedded `abi_recipe`), `domain`
  (`description`, `axes`: name to `{coverage, required}` where coverage is
  `exhaustive|sampled|pinned|partial|unknown`), `outputs` (`[{name, type}]`,
  type `int|bytes|json`), `normalizations` (`[{name, params}]` from the
  registry below), `limitations`, `required`, optional `success_outcome`
  (`pass` or `rejected_expected`), optional `accepted_adapter_digests`, `digest`.
- `ds1edit.baseline/1`: `build` = `vanilla-113c`, `binaries`
  (`[{name, sha256, size, pe?}]`), ordered `archives`
  (`[{name, priority, sha256, size}]`), `enumeration`
  (`sources`, `limits`, `complete`), `assets`
  (`[{path, archive, size, sha256, original_path?, kind?}]`, paths lower-case
  with backslashes), `render`, `digest`. Local installation paths are never
  recorded.
- `ds1edit.capture/1`: `contract_id`, `contract_digest`, `baseline_digest`,
  `adapter` (`name`, `version`, `abi_recipe_digest`, ...), `adapter_digest`,
  `original` (`module`, `module_sha256`, `rva`, `function_bytes_sha256`),
  `captured_at` (UTC `...Z`), `evidence` (`[{kind, ref}]`), `vectors`
  (`[{id, input, output}]`, ids unique, at least one), `input_sha256`
  (of `[{id, input}]`), `output_sha256` (of `[{id, output}]`), `limitations`,
  `digest`. A non-zero `truncated` field is refused.
- `ds1edit.case/1`: `id`, `lane`, `platform`, `required`, `status`,
  `success_outcome`, `contract_digest`, `baseline_digest`, `input_sha256`,
  `expected_sha256`, `actual_sha256`, `coverage`, `failures`, `provenance`
  (`candidate` and `reference`), `limitations`.

Statuses are exactly `pass`, `mismatch`, `unavailable`, `not_run`, `partial`,
`rejected_expected`. Only a required case whose status equals its contract's
`success_outcome` qualifies (`compare.qualifies`). A required axis whose
coverage is `partial` or `unknown` turns agreement into `partial`. Distinct
inputs, not calls, are counted. Failure entries carry the vector id, the first
differing path, and expected/actual values; for normalized outputs the
expected value is shown after normalization.

Normalizations (anything else is refused when the contract loads):

- `index_offset` `{output, offset, applies_to: expected|actual}`: makes a
  reference's relative index absolute.
- `mask_pointer` `{outputs, reason}`: compares only NULL versus non-NULL.

Candidate results passed to `compare_case` are
`{lane, platform, provenance: {source_state, executable: {sha256}, build, packages}, vectors: [{id, output}]}`.

## Palette nearest-colour pilot (`palette-nearest-113c`)

Compares the editor's `palette_find_closest` (`src/core/palette.c`) with
`D2CMP.dll` 1.13c RVA `0x9d30` (export ordinal 10049). The ABI recipe embedded
in the contract was read from the identified binary's disassembly: `stdcall`,
five stack dwords `(entries, count, c0, c1, c2)`, stride 4 with byte k compared
to `c_k`, unsigned strict-less minimum (the first index wins ties), result in
`AL`, no register inputs, globals, calls, or relocations. The capture passes
`entries = palette + 4` and `count = 255`, so transparent index 0 is excluded
from both sides; the relative index is made absolute by `index_offset +1`.

Inputs (`fixtures/palette-nearest-inputs.json`, 336 distinct queries) are
generated by `capture_palette.py inputs`: a palette with distinct colours
`(i, 73i mod 256, 151i mod 256)`, exact queries for indices 1 to 255, the
0/127/255 RGB grid, index-0 colours, and a second palette with duplicate and
equidistant entries. The contract does not establish which channel order the
game's own palettes or callers use; that was settled separately against the live
game: a PL2 palette entry is stored red, green, blue
([palettes and colour](../../docs/guides/palettes-and-colour.md)).

Result on 2026-10-22: the editor's nearest-colour matcher agrees with the
original D2CMP 1.13c on all 336 vectors (CTest `equivalence_palette_replay`).
That is agreement for this finite input set, not for every possible input.

`fixtures/palette-nearest-baseline.json` is an identity-only baseline (binary
and archive hashes, no assets) generated from the local 1.13c directory.
`fixtures/palette-nearest-capture.json` was captured on 2026-10-22 from an idle
`lod-113c` d2-fleet member after the live `D2CMP.dll` `.text` section and the
function bytes matched the baseline.

## Commands

Replay (portable):

```sh
python -m scripts.equivalence.replay \
  --contract test/equivalence/contracts/palette-nearest-113c.json \
  --baseline test/equivalence/fixtures/palette-nearest-baseline.json \
  --capture test/equivalence/fixtures/palette-nearest-capture.json \
  --probe <build>/test/<config>/test_palette_reference_probe \
  --out-dir tmp/equivalence/replay
```

Compare an arbitrary candidate result:

```sh
python -m scripts.equivalence.compare --contract C --baseline B --capture K \
  --actual A --out case.json     # exit 0 success, 1 mismatch, 2 invalid/unavailable/partial
```

Local corpus manifest (writes under `tmp/`, which is gitignored):

```sh
python -m pip install --user -r test/equivalence/requirements-local.txt
python tools/d2mpq.py selfcheck --version "<1.13c directory>"
python -m scripts.equivalence.baseline --game-dir "<1.13c directory>" \
  --extra-names tmp/equivalence/extra-names-113c.txt \
  --out tmp/equivalence/baseline-corpus-113c.json
python -m scripts.equivalence.baseline --game-dir "<1.13c directory>" \
  --scope identity --out tmp/equivalence/baseline-identity-113c.json
```

`--extra-names` supplies names for `Patch_D2.mpq`, which has no `(listfile)`;
use the union of the sibling archives' listfiles. Without it the manifest
records the limitation and patch-only members cannot be enumerated.

Live capture (only on an idle member dedicated to testing):

```sh
export D2FLEET_TOKEN=...   # read from the environment, never stored
python -m scripts.equivalence.capture_palette capture \
  --contract test/equivalence/contracts/palette-nearest-113c.json \
  --baseline test/equivalence/fixtures/palette-nearest-baseline.json \
  --inputs test/equivalence/fixtures/palette-nearest-inputs.json \
  --fleet-root ../d2-fleet --host <host> --port <port> --out tmp/equivalence/capture.json
```

A capture is refused (exit 2) on any changed binary, function byte,
relocation, recipe, missing privilege, fault, timeout, member death, or
out-of-range result. A partial capture is never written. Never replace a
tracked capture with candidate output; a changed contract, baseline, or adapter
needs a fresh live capture.

## Other tools in `scripts/equivalence/`

Each module's docstring is the authoritative description; `--help` on the
command-line ones lists their options.

| Module | Lane | Purpose |
| --- | --- | --- |
| `contracts.py`, `compare.py`, `replay.py` | portable | Contract schemas, case comparison, recorded replay (see above) |
| `baseline.py`, `capture_palette.py`, `fleet_adapter.py` | local / live | Corpus manifest, fresh original-game capture through a d2-fleet member (`D2FLEET_TOKEN`) |
| `ds1_reference.py`, `ds1_cases.py`, `ds1_sweep.py` | local corpus | Original-game DS1 loader reference (D2Common 1.13c), map snapshots, and the sweep that reads and resaves every catalogued vanilla DS1 through the editor's reader and checked writer (needs `mpyq` and a 1.13c install). Last run: all 2 276 read and resave cleanly, 2 238 identical to the original loader; the other 38 were the out-of-bounds-object drop that is being fixed, so re-run to confirm |
| `decoder_cases.py`, `export_cases.py`, `visual_values.py` | portable | Authored fixtures and independent expectations for DCC/DC6, PNG/APNG exports, palette, tile-key and AnimData behaviour |
| `adversarial.py` | portable | Deterministic malformed-input campaigns against the C probes (CTest `adversarial_core`; 6 717 cases found and fixed a DCC sub-stream overrun and two DT1 32-bit wraparounds) |
| `render_cases.py` | local corpus | Pinned-input map renders for the golden comparison (`profiles/visual-core.json`) |
| `benchmarks.py` | local | Repeated-workload timing records; comparisons stay unreviewed until a maintainer reviews a budget. Refuses instrumented builds |
| `coverage_report.py` | CI / local | Aggregates `gcov --json-format` or `llvm-cov export` output; partial coverage is reported, never counted as covered |
| `package_check.py`, `native_smoke.py` | package | Inspect a CPack archive, and run the *extracted* executable (help, no-game start-up, selftest, platform start-up) |
| `qualify.py` | release | Binds every required result to one candidate and decides readiness against `profiles/release-core.json`. Current verdict: NOT READY, 11 of 164 required entries qualify |

Run the Python suites for all of these with
`python -m unittest discover -s test/python -t . -p "test_*.py"` or through CTest
(`py_*`, label `portable`). Install `test/python/requirements.txt` for those and
`requirements-local.txt` (adds `mpyq`) for the local corpus lane only.
